### Проекты

#### [SplitMaster Simple](https://github.com/TeskiOke/SplitMasterSimple-Release) · [Showcase](https://github.com/TeskiOke/SplitMaster-Showcase)
Flutter-приложение для совместного учёта расходов в реальном времени.
- Синхронизация через Supabase + Firebase Firestore
- Push-уведомления через FCM + Node.js
- UI на Flutter, архитектура MVVM + Provider

#### [RadCord 1.0](https://github.com/TeskiOke/RadCord-1.0)
P2P-коммуникатор для локальных сетей и Radmin VPN. Python + PySide6.
- Текстовые каналы, голосовой чат (VAD), демонстрация экрана
- P2P WebSocket mesh без выделенного сервера
- Захват системного звука, аудиомикшер, глобальные горячие клавиши

#### [RadCord 2.0](https://github.com/TeskiOke/RadCord-2.0)
Переработка RadCord на C# (.NET 8) + WPF с расширенным функционалом.
- Передача файлов в чате (chunked), захват ProcessLoopback
- MVVM (CommunityToolkit), Fleck WebSocket сервер
- Поддержка нескольких сетей одновременно

#### [TeskiNety](https://github.com/TeskiOke/TeskiNety)
Инструмент для создания виртуальных частных сетей поверх интернета.
- WPF-клиент на C# + Python рандеву-сервер
- Туннелирование через WinTun, шифрование AES-GCM
- Автоматическое установление P2P-соединений через relay

#### [HonorEarbuds](https://github.com/TeskiOke/HonorEarbuds)
Управление Honor Choice Earbuds X5 Pro с Android и Windows без официального приложения.
- Реверс-инжиниринг Honor SPP Bluetooth протокола (CRC16-Xmodem)
- Flutter-приложение (Android) + Python-клиент (Windows WinRT)
- Заряд, ANC, EQ, Home Widget

#### [SkyblockScripts](https://github.com/TeskiOke/SkyblockScripts)
Инструменты для Hypixel Skyblock: JS-макросы и Python-калькуляторы.
- JS-макросы для JsMacros (Bazaar API, автофарм, калькуляторы доходности)
- Python-утилиты: фарминг, майнинг, мутации, трекер сессий ПК

#### [Freelance Monitor](https://github.com/TeskiOke/Freelance-monitor)
Автоматический мониторинг заказов на Freelancehunt в реальном времени.
- Python-скрипт с парсингом и фильтрацией по ключевым словам
- Уведомления через Telegram Bot API

#### [Support Auto-Responder](https://github.com/TeskiOke/Support-bot)
Telegram-бот с автоматической обработкой обращений.
- База ответов на JSON, многоуровневая маршрутизация тикетов
- Стабильная работа в production
